
# Number Checker

A simple C++ program that checks whether a number entered by the user is odd or even.

## Language
- C++

## How to Run

Compile the program:

    clang++ main.cpp -o odd_even

Run the program:

    ./odd_even

## Functionality
- Accepts an integer from the user.
- Checks whether the number is divisible by 2.
- Displays whether the number is odd or even.
